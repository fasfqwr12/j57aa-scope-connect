# Quiet Olive：设计依据与验收记录

本文记录 Quiet Olive 基线的设计与验证，不以测试数量代替视觉质量。基础配色资源版本为 `quiet-olive-03`；手机单屏布局与入口脚本版本为 `mobile-screen-05`。

## 手机单屏布局

| 维度 | 原手机版 | 单屏手机版 |
|---|---|---|
| 页面高度 | **整页纵向延展** | **固定可视区高度** |
| 长内容 | **上下堆叠** | **页内分组切换** |
| 预览 | **页面底部展开** | **按需模态弹出** |
| 短屏溢出 | **整页滚动** | **仅内容区滚动** |
| 升级中止 | **确认区内** | **升级页固定底栏** |
| 桌面布局 | 原分栏布局 | 同上 |

共性：保留原控件、事件与升级门禁。
关键差异：一屏外壳，不裁切长内容。

采用可逆节点移动，不复制表单、文件输入或状态；跨900像素断点还原桌面DOM。预览关闭后焦点返回入口。软键盘可视区变化参与高度计算，但桌面iframe不能替代真实手机键盘验收。

`mobile-screen-05` 补充了窗口 resize 的断点复核，并统一使用当前布局视口宽度。此前在 Edge iframe 中实测收到 resize、未收到原媒体查询 change，导致桌面缩至手机后未挂载；这不是已证实的缓存故障。测试会先核对入口资源版本，保持被测 iframe 可见，并在失败时输出实际视口与资源诊断。

手机专用检查 `tests/mobile-screen-smoke.html` 本地通过 **3598/3598**；覆盖320×568、360×640、390×844、430×932、768×1024、844×390、390×420，以及900/901断点往返两轮。390×844默认七页均无内容区纵向溢出；360×640仅升级默认页需内容区滚动。更矮视口不承诺所有内容同时可见，验证的是不产生整页滚动且内容末尾可达。

测试在应用启动前隔离存储与硬件访问，网络请求使用本地503响应；长文本测量阶段暂停测试内的定时渲染，避免人工注入的门禁文字被真实定时刷新覆盖。生产门禁逻辑未改。另用浏览器按键操作核验 Escape 关闭与焦点返回，通过1项；与自动检查合计3599项。该测试不代表在线固件目录、真实手机键盘或安全区验收。

## 设计依据

- [Linear：How we redesigned the Linear UI](https://linear.app/now/how-we-redesigned-the-linear-ui)：减少界面噪音、建立导航层级、保持跨区域对齐。不照搬其布局或素材。
- [Radix Themes：Typography](https://www.radix-ui.com/themes/docs/theme/typography)：字号、行高、行宽共同构成阅读比例，使用有限尺度而非逐块随意设置。

取舍：保留低饱和橄榄色识别，用暖白底和灰绿信息条代替大面积深色；保留风险提示、实际状态和明确确认，不用口号制造层级。
