# Olive UI 界面优化记录

本轮只调整页面结构、样式及展示交互；不修改升级协议、固件校验、确认门禁或设备端源码。

## 主要调整

- 暖灰卡其底色搭配深绿导航，统一卡片、标题、输入框和主按钮层级。
- 手机优先显示操作区，预览默认折叠，支持展开及收起。
- 高级连接参数默认收起，保留原有字段、默认值和修改能力。
- 升级页移除无关预览栏，宽屏分栏，窄屏依次显示检测和固件选择。
- 固件卡片分开显示名称、说明和选中状态，下载核验仍不直接授权刷写。
- 保留检测副作用、待真机验收及失败恢复提示。
- 增加导航辅助状态、可见键盘焦点和减少动态效果支持。

## 复现方式

在项目HTTP(S)地址打开 `tests/browser-smoke.html`；添加 `?width=390` 可单独检查一种宽度。

```powershell
node --check src/app.js
node --check src/upgrade/ota-ui.js
node --test --test-reporter=spec tests/ota.test.mjs tests/ota-boundaries.test.mjs
```
