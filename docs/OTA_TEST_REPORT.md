# 状态优先 OTA：软件验收记录

结论：当前源码的离线回归和本地浏览器交互检查通过；**不是蓝牙真机或刷写验收通过**。

## 可重复验证

| 维度 | 协议与模拟设备回归 | 浏览器交互检查 |
|---|---|---|
| 已通过数量 | **53项** | **101项** |
| 测试环境 | **Node测试运行器** | **Edge** |
| 真实蓝牙 | 禁止访问 | 同上 |
| 真实擦写 | 未执行 | 同上 |
| 主要覆盖 | **帧与升级安全边界** | **导航和页面门禁** |

共性：结果只证明软件测试范围。
关键差异：视口模拟不是真机触摸测试。

运行协议回归：

```powershell
node --test --test-reporter=spec tests/ota.test.mjs tests/ota-boundaries.test.mjs
```

浏览器检查：通过项目 HTTP(S) 地址打开 `tests/browser-smoke.html`。测试使用同源 iframe 加载当前应用，在任何应用脚本前拦截蓝牙请求，并检查运行错误与资源加载错误。

## 已覆盖边界

- 主控与副板分别识别；F7及代理应答不能代替副板自身应答。
- 全部九种 APP/Boot/未知模拟组合；不可达不显示成空白固件。
- 独立CRC参考向量、任意两段通知分片、GLPE镜像和业务帧隔离。
- 外层事件跨请求、空闲时段和独占会话切换仍保持完整边界。
- GLPX占用不抢占；未确认回包、清理失败和迟到回包不能放行升级。
- BIN/HEX目标、元数据、硬件版本、CRC、窗口和复位向量检查。
- 在线固件长度、SHA-256、整文件CRC与元数据CRC核对。
- 逐包ACK、写入计数偏差、校验失败、APP未确认均停止且不假报成功。
- 超时停止后续GATT分片，等待正在执行的原生写入结束才释放通道。
- 提前ACK、写入失败、断连和取消不会提前释放事务所有权。
- 普通读取禁止相互覆盖；升级独占期间禁止普通请求。
- 重连重新获取特征并订阅通知，旧状态快照失效。
- 320、390、768、1440 CSS像素下的七页切换、活动页唯一性及无横向溢出。
- 取消检测不请求设备；只下载固件仍不能绕过“先检测双板”的门禁。
- 上述四种视口检查中未捕获应用运行或资源加载错误。

## 未验收范围

- 未连接设备；未擦除、写入或复位任何主控/副板。
- 未证明现场Boot/APP镜像对应当前源码或在线候选文件。
- 27字节GLPX单次GATT写入到UART完整块的实际行为尚未验证。
- 未测试真实吞吐、供电切换、后台/锁屏、手机蓝牙栈或断电恢复。
- N32刷写、Boot自升级、ENC与自动断点续写未实现或未开放。
- 当前无service worker，不承诺断网冷启动或离线固件库。
