手机一屏主 Tab：离线 DOM 烟测

从现有同源 HTTP(S) 站点打开本页。无依赖，不下载固件，不点连接、检测、升级、同步或弹道操作。srcdoc 中先隔离存储、拒绝蓝牙和 Bridge，再加载应用。所有应用 fetch 返回本地 503 fixture；静态脚本/样式/图片仍从本站加载。

默认覆盖 7 个宽高以及 900/901 断点往返两轮。可指定 ?width=390&height=844&review=upgrade；review=device 或 upgrade 最终停第一子页。折叠列表含实际值。内部长文/日志滚动仅 INFO，几何越界才 FAIL。

边界：iframe 只模拟 CSS 视口，不模拟实际键盘、safe-area、触摸、可信按键。自动检查模态与关闭焦点；真实 Escape 须点击下方人工按钮后按 Escape，结果会追加。PASS 不代表这项人工检查已执行。
